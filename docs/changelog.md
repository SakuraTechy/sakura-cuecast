# 官方更新日志

## 2026-08

- CDP 批量回放新增“每条用例独立登录”“复用上一条用例的登录态”“同一浏览器窗口连续执行”三种用例会话模式；失败时重置受影响上下文，认证快照仅在扩展会话内保存，并保留旧版当前浏览器兼容模式。
- 修复步骤数量超出限额时，保存步骤变少的问题。
- 优化分组卡片 Base URL 展示：仅在超出宽度时省略。
- 修复视觉隐藏的单选框和复选框回放。
- 录制面板支持「记录悬浮」，可为需要 hover 才显示的菜单或浮层手动生成悬浮步骤。
- 支持在创建用例时设置执行窗口尺寸。
- 支持在用例列表页编辑分组详情。

## 2026-07

- 新增组织工作区：支持默认组织、成员管理、邀请链接、成员角色、移除成员和组织切换。
- 新增订阅管理：展示当前套餐、到期时间、余额、代金券、用例数、执行次数和成员数。
- 新增邮箱登录、邮箱绑定、修改密码和忘记密码流程。
- 新增通知管理页：Webhook 从执行计划页迁出，并支持将执行结果发送到组织成员邮箱。
- 优化下载等场景下的冗余点击录制。
- 新增执行失败反馈入口：执行详情失败时可提交“反馈该问题”，支持补充说明和粘贴截图。
- 「从这里开始录制」支持先执行前置步骤恢复页面上下文。
- 智能步骤支持自动识别验证码图片，方便应对简单登录场景。
- 失败分析能力大幅增强，结合规则和AI双重判断，增加更多判断证据。
- 断言能力补充整页文本和 URL 目标：用例详情编辑断言步骤时可切换到整页文本或 URL，URL 断言支持包含、等于、不包含和正则匹配。
- 录制面板支持直接添加元素断言：录制中点击「添加断言」后点选页面元素，可生成文本包含、文本等于、输入值等于或元素可见断言步骤。
- 用例详情新增步骤列表视图，执行详情新增明细视图。
- 优化动态定位属性过滤：录制时自动避开运行时动态定位信息，减少页面刷新或组件重渲染后定位失效。
- 用例列表支持单条和批量复制用例：可指定目标分组，复制用例配置和步骤。
- 新增数据变量能力：支持保存页面值为变量，后续通过 引用；支持完整值、AI 智能抽取规则和正则匹配。
- 录制与回放支持多标签页上下文：可录制由当前页面打开的浏览器新 tab，自动生成"切换标签页"步骤。
- 支持 contentEditable 元素（富文本编辑器）输入录制与回放。
- 支持原生 select 下拉框的录制与回放。
- 支持虚拟滚动元素的录制与回放。
- 优化页面跳转时的点击记录。
- 执行计划支持登录准备：可在计划开始前自动判断登录态，已登录跳过、未登录先执行登录用例。
- 优化执行结果截图加载：截图按步骤按需加载、支持录制截图/执行截图/对比视图三档切换。
- Tree 组件录制与回放全面增强：录制时自动识别节点标题、父路径、层级等上下文，回放使用多因子评分定位，减少节点误点击。
- 支持 Monaco 编辑器内输入录制与回放，适配基于 VS Code 的在线编辑器场景。
- 优化禁用态元素判断：收敛为仅检查交互组件根节点，避免父级容器 disabled class 误伤内部按钮。
- 优化 hover 录制策略：仅在后续点击依赖该 hover 时才保留 hover 步骤，减少鼠标扫过产生的冗余步骤。

## 2026-06

- 用例列表和执行计划列表支持更多的排序和筛选。
- 输入步骤动态值新增组合值模式，可任意拼接固定值、日期、随机数字、随机字符串和时间戳。
- 支持配置用例执行窗口尺寸，默认全屏。
- 修复执行计划删除无效的问题。
- 新增白天主题，可自由切换黑夜主题与白天主题，增强体验感。
- 优化工作台信息展示。
- 在工作台、分组管理、用例详情、执行详情、执行计划和计划详情等页面增加刷新按钮。
- 执行计划支持 Webhook 通知，可将执行结果自动推送到飞书、钉钉或企业微信群聊。
- 新增断言步骤入口，优化断言表单，可选择整页文本、指定元素或错误提示，并配置包含、等于、不包含或正则匹配。
- 用例支持「从这里开始执行」，只回放后续步骤；执行详情会提示起始步骤，完整展示步骤链路，并从实际执行步骤开始高亮。
- 优化智能步骤的稳定性和准确性，适配更多场景。
- 录制过程中如果页面发生整页跳转或刷新，扩展会自动恢复录制工具栏，并尽量保留已录步骤，减少录制中断后步骤丢失。
- 优化从这里开始录制功能：录制前会提示新步骤的插入位置，并自动选择更合理的起始页面，避免误覆盖已有步骤。
- 录制支持双击和右键点击。
- 输入步骤支持动态值配置，适合需要每次新建数据不能重名的场景。
- 支持用例级 AI 失败分析，开启后可辅助理解错误日志和失败原因。
- 支持自然语言智能步骤，用一句话描述操作意图即可辅助生成执行动作。
- 录制密码框时自动脱敏，密码加密存储，中台不显示明文；修改密码需重新输入并保存。
- 优化表格内操作、浮层内操作及悬停触发场景的录制与回放稳定性。
- 新增 Chrome 扩展分步安装向导。
- 修复顶部切换项目后部分页面仍显示旧项目数据的问题。

## 2026-05

- 优化工作台当前结论口径，优先看最近一次计划执行和当前失败用例；历史失败与 Flaky 作为风险提示保留。
- 优化输入后按回车的录制与回放稳定性，减少回放时回车未生效的问题。
- 输入后立刻停止或暂停录制时，会更可靠地保留最后输入的内容。
- 优化下拉搜索框输入后按回车的处理，减少重复确认或未确认的情况。
- 步骤输入值支持手动开启脱敏展示。开启后，步骤页和报告页只展示脱敏值，回放仍使用原始录制值。
- Chrome 扩展支持版本更新提示。平台检测到本地扩展版本落后时，会提示用户下载并更新扩展。
- 优化 Select/Combobox 等下拉组件的录制与回放定位稳定性。
- 执行计划支持「失败即停止」策略，适合发布前冒烟回归。
- 用例支持标准截图和高清整屏截图两种策略。
- 用例步骤支持追加录制、拖拽排序、复制粘贴、批量操作和撤销。
- 工作台增加发布信号、风险聚焦和稳定性风险视图。
